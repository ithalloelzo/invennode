# InvenNode: Code Lab

Este projeto foi desenvolvido como parte da Iniciativa Code Lab, do Instituto Programadores do Amanhã, com o objetivo de desenvolver um probjeto backend, com a linguagem JavaScript, utilziando Node.Js e a biblioteca Express. A proposta é criar uma API Rest, no protocolo HTTP com as operações CRUD(Criar, Ler, Atualizar e Deletar) que resolva o problema de alguma empresa.
O objetivo do projeto é solucionar o problema do microempreendedor que está cansado de perder o controle de suas vendas em caderninhos que somem. 

## 📋 Funcionalidades
-Cadastro de Produtos: controle de estoque na palma da mão.
-Gestão de Clientes: saiba exatamente para quem você está vendendo.
-Notas de Venda Rápidas: geração de registros a partir dos seus cadastros.

## 🛠️ Tecnologias Utilizadas
- JavaScript: Linguagem principal para a lógica do projeto.
- Node.js
- Express
- Nodemon
- Validation.js
- Git & GitHub: Utilizados para o versionamento do código, seguindo o padrão de semantic commits.

##⚠️Pré Requesitos:
- Node.js 

## ⚙️ Como Executar o Projeto
1. Abra o terminal na área de trabalho e digite:
```
git clone https://github.com/ithalloelzo/turing-function.git
```
2. Abra a pasta utiliando VS Code ou qualquer outro editor de sua preferência
3. Abra o terminal para instalar todas as dependências do projeto e digite:
```
npm install 
```
4. Digite o comando:
```
npm run dev 
```
